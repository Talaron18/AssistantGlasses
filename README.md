# 智能助盲眼镜
## 视觉模块
### 功能
1. 辅助避障
识别视线前方静止和靠近的障碍物，需要检测距离。
- 距离检测
- 障碍物识别
2. 盲道识别
保障盲人在盲道可用的情况下优先使用盲道，如果检测到盲道上有障碍物，自动规划新路线
- 基于CV的巡线
3. 拍照功能
根据语音指令启动
- cv
4. 红绿灯识别（如果导航模块接入物联网就不需要）
- yolo?
5. 辅助取物 (根据时间考虑，可以不用)
- cv
- yolo
### 硬件
- 摄像头*2（可以考虑低配+高清结合，也可以双高清做双目识别）
- 微型震动马达*4 （辅助指引盲人）
- 耳机（对话功能）
- 麦克风（如果是蓝牙耳机自带麦克风就不需要）
## 硬件设计
- 确认需要购买的硬件尺寸（尽量小）
- 根据硬件制作眼镜框
- 设计背包框架（用来装开发板和电池）
